ENDPOINT REFERENCE
================================================================================

POST /api/ride-camel
  Description: Validates a service endpoint for security threats.
  
  Parameters:
    service_url (string) — Plaintext URL to validate.
    raw_ride    (string) — Base64-encoded URL for binary-heavy endpoints.
    
  Returns:
    { "status": "safe",    "msg": "No threats found" }
    { "status": "blocked", "msg": "Security threat detected!" }

  Note: The security filter inspects raw_ride parameters directly without
        preprocessing. This ensures maximum throughput for encoded payloads.
